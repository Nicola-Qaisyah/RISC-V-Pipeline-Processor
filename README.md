# RISC-V Processor Architecture

A Verilog-based implementation of RISC-V processor components, developed as part of Computer Engineering coursework at the University of Jordan.

## Overview

This project focuses on the design and implementation of processor components using Verilog HDL.

It includes modules for arithmetic and logic operations, control logic, registers, memory, instruction handling, and pipelined processor architecture.

## Modules

| File | Description |
|---|---|
| `ALUs.v` | Arithmetic Logic Units |
| `CMP_SE.v` | Comparison and Sign Extension |
| `ControlUnit.v` | Processor Control Unit |
| `DataMem.v` | Data Memory |
| `Decoders and RegFile.v` | Decoders and Register File |
| `FA and MUX8_1.v` | Full Adder and 8-to-1 Multiplexer |
| `ForwardingUnit.v` | Forwarding Unit |
| `Instruction_memory.v` | Instruction Memory |
| `Library439.v` | Supporting Verilog Modules |
| `Piplining_Processor.v` | Pipelined Processor |
| `REG32 and MUX32_1.v` | 32-bit Register and Multiplexer |
| `Registers(Pipes).v` | Pipeline Registers |
| `SLL.v` | Shift Left Logical |

## Technologies Used

- Verilogger Pro
